ensembl.vep.models.overlap.overlap_consequence module#

OverlapConsequence class.

class ensembl.vep.models.overlap.overlap_consequence.OverlapConsequence(*, term, accession, is_default=False, rank=0, tier=0, impact=ConsequenceImpact.LOW, feature_type=<class 'ensembl.vep.models.feature.Feature'>, overlapping_feature_type=<class 'ensembl.vep.models.feature.Feature'>)[source]#

Bases: object

A predicted consequence of an overlap between a feature and a base feature.

This is typically used to represent the consequence of a variant on a transcript, but it can be used for any type of feature overlap.

Variables:

  • term (str) – The SO term for the consequence, e.g. “missense_variant”.

  • accession (str) – The SO accession for the consequence, e.g. “SO:0001583”.

  • is_default (bool) – Whether this consequence is the default consequence for the overlapping feature. Only one consequence can be default, for transcript variation allele it is generally intergenic_variant.

  • rank (int) – The rank of the consequence, with 1 being the most severe.

  • tier (int) – The tier of the consequence. If tier 1 consequence are assigned, then no tier 2 consequences will be checked or assigned.

  • impact (ConsequenceImpact | None) – The predicted impact of the consequence, e.g. “HIGH”, “MODERATE”, “LOW”, “MODIFIER”.

  • feature_type (type[Feature] | None) – The type of the overlapped feature that is affected by this consequence type, e.g. Transcript.

  • overlapping_feature_type (type[Feature] | None) – The type of the overlapping feature that causes this consequence type, e.g. VariationAllele.

class ensembl.vep.models.overlap.transcript_variation_allele.TranscriptVariationAllele(*, feature, overlapping_feature, is_reference=False, readthrough=Readthrough.NONE)[source]#

Bases: FeatureOverlap

Represents the overlap between a transcript and a variation allele.

Variables:

  • feature (Transcript) – The transcript that is getting overlapped.

  • overlapping_feature (VariationAllele) – The variation allele that is overlapping.

  • is_reference (bool) – Whether the overlapping variation allele is the reference allele.

  • cdna_position (Position | None) – The variant’s position on the spliced transcript, or None if it touches no exon.

  • cds_position (Position | None) – The variant’s position on the CDS, counted from a whole first codon, or None if it does not touch the CDS.

  • protein_position (Position | None) – The residues the variant’s two ends fall in, or None if it does not touch the CDS.

  • distance_to_transcript (int | None) – The distance from the variation allele to the transcript, or None if the variation allele overlaps the transcript.

  • exon_number (int | None) – The exon number of the transcript that is overlapped by the variation allele, or None if the variation allele does not overlap any exon.

  • intron_number (int | None) – The intron number of the transcript that is overlapped by the variation allele, or None if the variation allele does not overlap any intron.

  • reference_codon (str | None) – The reference allele’s whole-codon window in the CDS (transcript-sense), covering every codon touched by the variant, or None if the variant does not overlap the CDS. Cased for display as VEP writes it: lower case but for the allele’s own bases.

  • alternate_codon (str | None) – The alternate allele’s whole-codon window in the CDS (transcript-sense), i.e. reference_codon with the variant allele spliced in, or None if not applicable. Cased the same way, so a deletion’s is all lower case.

  • reference_peptide (str | None) – The amino acid translation of reference_codon, or None if not applicable.

  • alternate_peptide (str | None) – The amino acid translation of alternate_codon, or None if not applicable.

  • reference_cds (str | None) – The whole reference CDS (transcript-sense, includes the start and stop codon), or None if the transcript has no CDS at all.

  • alternate_cds (str | None) – The whole reference CDS (transcript-sense) with the variant allele spliced in, or None if not applicable.

  • reference_cds_peptide (str | None) – The amino acid translation of reference_cds, or None if reference_cds is None.

  • alternate_cds_peptide (str | None) – The amino acid translation of alternate_cds, or None if alternate_cds is None.

  • readthrough (Readthrough) – How far translation of alternate_cds may run when the variant destroys the stop codon.

property cds_length_change: int | None#

Net change in coding length the variant makes, in bases.

Positive for an insertion, negative for a deletion, zero for a substitution. Derived from the CDS edit geometry rather than the cDNA. Any intronic portion of the variant’s genomic span is already discounted, since the offsets come from the mapper’s block-overlap clipping.

Returns:

The net coding length change, or None when the variant does not overlap

the CDS and so changes no coding length at all.
