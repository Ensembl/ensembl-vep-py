property cds_mapper: Mapper | None#

Public accessor for _cds_mapper.

Offsets are CDS-relative: offset 0 is the first base of the start codon, and UTR bases map to nothing at all. A CDS with an incomplete 5’ end starts at offset cds_start_phase instead, the offsets before it being VEP’s N padding. Use this for anything expressed in coding coordinates, e.g., codon windows, protein offsets. Its sibling cdna_mapper covers the whole spliced transcript instead; the two disagree by cdna_coding_start - 1 over the CDS, and only cdna_mapper can place a UTR position.

Returns:

The genomic<->CDS<->protein coordinate mapper for this transcript’s

CDS, or None if the transcript is not coding.

Return type:

Mapper | None
