Input buffers: a batch of input objects, indexed for overlap discovery.

class ensembl.vep.buffer.input_buffer.base.InputBuffer[ObjectT: IntervalLike](*, objects=())[source]#

Bases: Generic[ObjectT]

Indexed batch of input objects for overlap discovery.

The index is built on the first query and discarded whenever the batch changes, so a buffer that is only ever filled costs nothing to index.

Variables:

objects (tuple[ObjectT, ...]) – The objects in the current batch, in input order.

class ensembl.vep.buffer.input_buffer.fixed_size.FixedSizeInputBuffer[ObjectT: Feature](*, objects=(), buffer_size=5000, max_not_ordered_variants=5, max_not_ordered_variants_distance=50)[source]#

Bases: InputBuffer[ObjectT]

Fixed-size input batch restricted to one sequence region.

An object read past the end of a batch, or on the next sequence region, is held back for the following refill rather than dropped.

Variables:

  • buffer_size (int) – How many objects one batch holds at most.

  • max_not_ordered_variants (int) – How many out-of-order objects to tolerate.

  • max_not_ordered_variants_distance (int) – How far back an object may start before it counts as out of order, which leaves room for deletions and minimised alleles.
