Evaluation contexts grouped by lifetime.

prepare(fact_context, *, apply_zone_map=True)[source]#

Apply every enabled cache to one overlap, before its facts are computed.

The single place the caches’ ordering is written down. Annotators call this once per overlap and are otherwise cache-agnostic. Turning a cache on or off is a change to the context a caller will make, not to the annotator.

Order is load-bearing and not arbitrary:

  1. Readthrough level first. It changes what the sequence tier will compute, and assigning it invalidates the overlap’s cached CDS alleles – so it has to land before anything reads them, for the same reason the codon cache has to land before the sequence tier are evaluated.

  2. Zone map second. It prefills the positional tier, including overlap_feature and overlap_exon, which is exactly what the codon cache’s gate reads next, so running it first makes that gate free rather than evaluated.

  3. Codon cache third, and still before any rule is evaluated. Injecting once the sequence tier has already been reached is too late: the evaluation cost has been charged and the cache saves nothing.

Parameters:

  • fact_context (FactContext[TranscriptVariationAllele]) – The overlap about to be evaluated.

  • apply_zone_map (bool, default: True) – False for a caller that will take the zone map’s answers over a whole batch of overlaps instead (ZoneMapCache.columns), for example, a batch annotator (columnar). Doing both would compute every zone fact twice.

readthrough: Readthrough#

class ensembl.vep.annotators.consequence.context.fact.FactContext[OverlapT_co: FeatureOverlap](*, overlap, recorder=None, annotator_context=None)[source]#

Bases: Generic[OverlapT_co]

Represent one variant-feature overlap during fact evaluation.

Wraps an overlap and stores its computed facts and other memoised values.

Variables:

  • overlap (OverlapT_co) – The variant-feature overlap being annotated. Callers should not replace it because the type parameter is covariant. Runtime immutability is not enforced because attrs.setters.frozen adds substantial access cost.

  • recorder (TraceRecorder | None) – Opt-in trace gatherer, or None to disable tracing entirely. It collects only what a later reconstruction cannot recover – read counts and which cache served which fact – so the whole cost of tracing on this class is one is not None check per fact lookup. See ensembl.vep.trace.

  • annotator_context (AnnotatorContext | None) – The run-scoped state this overlap is being annotated under or None when the context is evaluated standalone (e.g., unit tests).

Seed the memo table with already-known values, without charging their cost.
