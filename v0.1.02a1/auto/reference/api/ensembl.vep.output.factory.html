ensembl.vep.output.factory.base module#

Format-neutral annotated variants and their factory.

The factory is a port of the format-independent half of Perl VEP’s OutputFactory.pm. A variation first becomes a hash of what is known from its position alone (variation_hash). That hash is copied and extended once per (allele, feature) overlap (allele_hash). The copies are then filtered, picked or squashed as the options ask (output_hashes), and build_annotated_variant hands them to AnnotatedVariant.build, which detaches the variant’s own fields. The snapshot is the only thing that crosses a worker boundary and the only thing an output format sees.

Only fields this model can actually supply are ever populated. A column VEP fills from data not carried here yet – HGVS, SIFT, frequencies, co-located variants – stays empty rather than being approximated, which is VEP’s own convention for “not available”. The column layout for a given set of flags is VEP’s, so a downstream tool reading the Format declaration finds what it expects.

Consequences reach an allele through VariationAllele.transcript_variation_alleles. Assigning that list invalidates the allele’s aggregate, so assign each overlap’s consequences first and attach the overlaps afterwards.

ensembl.vep.output.factory.base.DEFAULT_PICK_ORDER = ('mane_select', 'mane_plus_clinical', 'canonical', 'appris', 'tsl', 'biotype', 'ccds', 'rank', 'length', 'ensembl', 'refseq')#

The order --pick weighs a transcript by, as VEP defaults it. A criterion this model has no data for ties for every candidate and so defers to the next one – exactly VEP’s behaviour when two candidates are equal on a criterion.
