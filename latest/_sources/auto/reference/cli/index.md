`make clidoc` from the option declarations, so they always match `vep <command> -h`.

## Setting options

Each option can be set in three places. When the same option is set more than once, the
later source in this list wins:

1. a config file passed with `--config FILE`, either TOML with one `[section]` table per
   option section, or a Perl VEP config file with one `option value` per line;
2. its environment variable, listed in each option table;
3. its command-line flag.

Options left unset take the default shown in the tables.

(cli-global)=
## Global options

| Option | Default | Description |
| ------ | ------- | ----------- |
| `--config FILE` | – | Read options from a TOML or Perl VEP config file. May appear anywhere on the command line. |
| `-h, --help` | – | Show the help for `vep`, a group (`vep <group> -h`) or a command. |

## Commands

| Command | Description |
| ------- | ----------- |
| {ref}`vep run default <cli-run-default>` | annotate variants against a set of annotation sources |
| {ref}`vep run haplo <cli-run-haplo>` | annotate phased haplotypes |
| {ref}`vep explain <cli-explain>` | explain one overlap's derivation, fact by fact and rule by rule |
| {ref}`vep stats <cli-stats>` | summarise an annotated file, or profile the facts over a corpus |
| {ref}`vep corpus describe <cli-corpus-describe>` | describe a registered corpus and list its selectable overlaps |
| {ref}`vep corpus golden <cli-corpus-golden>` | record or check the terms an annotator emits for a corpus |
| {ref}`vep corpus save <cli-corpus-save>` | write a registered corpus as FASTA, GFF3 and VCF |
| {ref}`vep bench endtoend <cli-bench-endtoend>` | time whole command-line runs over a corpus on disk |
| {ref}`vep bench matrix <cli-bench-matrix>` | time every strategy and cache configuration over a corpus |
| {ref}`vep bench oracle <cli-bench-oracle>` | compare our strategies with the Perl VariationEffect.pm oracle |
| {ref}`vep bench sweep <cli-bench-sweep>` | sweep one numeric annotation setting and time each value |
| {ref}`vep catalogue add <cli-catalogue-add>` | add a term to the consequence catalogue |
| {ref}`vep catalogue costs <cli-catalogue-costs>` | measure each fact's real cost against its declared tier |
| {ref}`vep catalogue remove <cli-catalogue-remove>` | remove a term from the consequence catalogue |
| {ref}`vep catalogue show <cli-catalogue-show>` | list catalogue terms or registered facts |
| {ref}`vep catalogue validate <cli-catalogue-validate>` | validate the consequence rule set |
