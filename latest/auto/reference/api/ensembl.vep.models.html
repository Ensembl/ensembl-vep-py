Bases: UnsafeSetterMixin

Represents a genomic feature in a specific locus.

Variables:

  • end (int) – End position relative to slice (1-based, inclusive).

  • strand (Strand) – Feature orientation relative to slice.

  • slice (Slice | None) – Slice object describing the feature context.

  • seq – Associated biological sequence.

end: int#
feature_slice()[source]#

Returns a slice that covers the area of this feature.

The feature start will be at 1 on the returned slice, and it will have the length of this feature. If the feature has no attached slice, a warning will be logged and None will be returned.

Return type:

Slice | None

Returns:

A Slice object covering the feature area, or None if the feature has no attached slice.
