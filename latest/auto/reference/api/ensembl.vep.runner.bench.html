ensembl.vep.runner.bench.endtoend module#

End-to-end command-line benchmarks over exported corpora.

class ensembl.vep.runner.bench.endtoend.Runner(config)[source]#

Bases: object

End-to-end benchmark runner for full CLI configurations.

The gate runs first and compares outputs rather than in-memory terms: a configuration whose annotated VCF disagrees with the reference’s is not timed. Each run is a separate process given this working copy on PYTHONPATH, so what is measured is the tree the benchmark was started from.

ensembl.vep.runner.bench.oracle module#

Case-by-case comparison with the Perl VariationEffect.pm oracle.

class ensembl.vep.runner.bench.oracle.Runner(config)[source]#

Bases: object

Oracle benchmark runner for Python and Perl strategies.

A disagreement is reported, never gated on: the oracle is the external reference, and the Perl script covers only four categories, so the question asked is whether our terms cover its terms.
