ensembl.vep.render.graph.layout module#

Placing a layered graph on a canvas.

These graphs are small – tens of facts and rules – and already carry the layer each node belongs to, so laying them out is arithmetic rather than a general graph-drawing problem. Layers become columns, and a node’s position within its column follows declaration order.

ensembl.vep.render.graph.layout.tree(graph)[source]#

Lay a child-to-parent tree out with every parent centred on its children.

Edges must point from an operand towards its parent. The one node with no outgoing edge is the root. Leaves keep graph declaration order, making the result stable while preserving sibling order from the source expression.

Raises:

ValueError – If the graph is disconnected, cyclic, or gives a node more than one parent.

Layout

ensembl.vep.render.graph.model module#

A directed graph carrying semantics, not styling.

A builder describes what a node is – its kind, which layer it belongs to, what state it ended in – and never what colour it should be. Renderers map those semantics onto an appearance, so every styling decision stays in one package and a builder needs no knowledge of the theme.

ensembl.vep.render.graph.svg module#

Rendering a laid-out graph as inline SVG.

The one place node semantics become an appearance: a builder says a node was forced false, this module decides that means a dashed grey box.

ensembl.vep.render.graph.svg.STATE_COLOURS = {'cached': Colour.NEON_BLUE, 'computed': Colour.ICE_BLUE, 'emitted': Colour.BLUE, 'false': Colour.RED, 'fired': Colour.LIGHT_BLUE, 'forced_false': Colour.LIGHT_GREY, 'impact_high': Colour.DARK_PINK, 'impact_low': Colour.DUCKEGG_BLUE, 'impact_moderate': Colour.ORANGE, 'impact_modifier': Colour.LIGHT_GREY, 'operator': Colour.LIGHT_GREY, 'prefilled': Colour.DUCKEGG_BLUE, 'pruned': Colour.MEDIUM_LIGHT_GREY, 'subsumed': Colour.DUCKEGG_BLUE, 'suppressor': Colour.DARK_PINK, 'term': Colour.LIGHT_BLUE, 'true': Colour.LIGHT_BLUE, 'unreached': Colour.WHITE}#

Node state -> fill colour. A state absent from here falls back to the neutral fill.

The one place a builder’s semantics become an appearance: subsumed and suppressor are the two directions of suppression, and they are coloured apart so which way it runs is readable without following the arrowheads.
