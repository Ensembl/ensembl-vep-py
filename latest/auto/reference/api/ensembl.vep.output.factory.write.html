ensembl.vep.output.factory.write.vcf module#

VCF output: the input line back, with a CSQ INFO field of pipe-separated consequences.

A port of Perl VEP’s OutputFactory/VCF.pm. A snapshot’s original VCF line is written back with any previous CSQ replaced. Each selected (allele, feature) record becomes one comma-separated chunk whose fields follow the Format the header declares – which is exactly what output/parser/vcf.py reads back.

A snapshot that did not come from a VCF line carries no columns, and VCF cannot invent them: an indel’s spelling needs reference bases, which a detached snapshot deliberately does not hold. So whoever builds such a snapshot supplies the columns, with the padding rule corpus/exporter/formats/file/vcf.py uses; writing one without them is refused rather than guessed at.
