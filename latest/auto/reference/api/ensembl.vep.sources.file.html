close()[source]#

Release the attached sequence source, if any.

FeatureSource owns the sequence_source field and __exit__ calls close(), but nothing in the chain ever released it – so a source opened as a context manager leaked its sequence handle. Closing it here is what the field’s ownership already implied.

get_all_records()[source]#

Return every unconverted record in the source file.

Returns:

Every record in the file.

Return type:

list[R]

Raises:

  • NotImplementedError – If the adaptor cannot parse a whole file at once. Re-raised with the adaptor named, which the bare error from the parser does not say.

  • FileNotFoundError – If the file does not exist. Allowed to propagate: its message already names the path.

A library reports what went wrong and lets its caller decide what to do about it. These both used to call sys.exit(1), which ended the process from underneath any caller – including a test, and including a runner that had a better answer than dying.
