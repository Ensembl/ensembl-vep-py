ensembl.vep.annotators.consequence.strategies package#

Interchangeable ways to evaluate the consequence rule set.

ConsequenceAnnotator is the shared implementation each strategy subclasses. The modules beside it are the strategies themselves. Importing this package registers every consequence.* annotator as an import side effect.

Registry names represent evaluation strategies rather than strategy-cache combinations. Callers configure zone-map and codon caches independently through the annotator context.

  • linear – rank-ordered scan with a cheap-guard digest cache. The conformance reference.

  • staged – cheap facts first, then requires propagation; expensive tier only on demand.

  • columnar – bit-parallel over a batch; cuts dispatch, not fact cost.

  • columnar-staged – both of the above: bit-parallel with forced-false staging masks.

  • columnar-kernels – columnar staging with selected columns filled by native batch kernels.

What was regular.columnar-staged-zonemap is now ColumnarStagedAnnotator(zone_map=ZoneMapCache(), codon_cache=CodonEditLRUCache()).

ensembl.vep.annotators.consequence.strategies.columnar module#

Evaluate consequence rules bit-parallel across an overlap batch.

Each fact is represented by a Python integer whose bit i contains the value for overlap i. Rule formulas become bitwise operations, paying Python dispatch once per rule and batch rather than once per rule and overlap.

Evaluation orders conjuncts by closure cost and carries a live mask of unresolved overlaps. A fact column is materialised only for that mask, while each plan node guarantees correct bits within its input mask and zero elsewhere. Because child masks and results only shrink, unpopulated bits cannot affect a decided result.

Default maximum number of overlaps evaluated together as one bit-parallel batch. Increase to amortise the plan-walking overhead over more overlaps, decrease to reduce peak memory usage. It has been observed that increasing does not always improve speed, because of big-int arithmetic overhead.

ensembl.vep.annotators.consequence.strategies.columnar_kernels module#

Columnar-staged evaluation whose cheapest fact columns are filled by native batch kernels.

Only flat integer arrays cross the native boundary; model objects remain in Python. Kernels process whole columns because a scalar boundary crossing costs more than the operations being accelerated.

The seeded facts cover short-variant shape and feature-span comparisons that remain per-context work after zone-map prefill. Exon and intron kernels are not seeded here because building their CSR arrays costs more than the Python scan when a zone map has not already supplied the values.

ensembl.vep.annotators.consequence.strategies.columnar_staged module#

Combine bit-parallel rule evaluation with staged fact propagation.

Cheap fact columns are materialised for the complete chunk. A topological sweep of the acyclic requires graph then propagates false bits into forced-false masks without per-context fixpoint work. This matches implied_false while preserving batch evaluation.

Forced-false masks may derive only from full-chunk columns or earlier forced masks. Values from a column populated for a smaller live mask cannot establish facts outside that mask.

ensembl.vep.annotators.consequence.strategies.linear module#

Evaluate consequence rules in rank order.

For each overlap, the strategy computes cheap guard facts, uses their digest to cache candidate rules, evaluates candidates in rank order, and applies subsumption.

This strategy is the conformance reference. Every other consequence strategy must produce the same ordered OverlapConsequence terms for the same input.

ensembl.vep.annotators.consequence.strategies.staged module#

Evaluate cheap facts before requesting expensive facts.

The strategy computes atoms below DEFAULT_CHEAP_ATOM_MAX_CLOSURE_COST, extends the assignment through implied_false, and partially evaluates each rule using three-valued logic.

A variant in an intron has overlap_exon = False, which makes overlap_cds false, which settles stop_gained, frameshift_variant, missense_variant and the rest of the coding tier as false without translating sequence.
