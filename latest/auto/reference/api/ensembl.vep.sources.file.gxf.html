ensembl.vep.sources.file.gxf.transcript module#

Shared GXF-based transcript source.

This module contains the common transcript-building workflow used by both file formats:

  • buffer records from the parser in streaming order,

  • group the buffered records into transcript-sized blocks,

  • build Transcript, Gene, Exon, and Translation objects (introns are derived lazily by Transcript itself), and

  • reuse Slice and Gene instances across records that share the same region.

Only the parser-specific record identity and parent resolution rules are left to the concrete GFF3 and GTF adapters.

get_features_by_region(region=None, *, seq_region_name=None, start=None, end=None)[source]#

Return complete transcripts whose spans meet one query region.

Two queries, because one is not enough: stage 1 finds the transcript rows overlapping the region, stage 2 queries the full span of each candidate not already pooled, so exons and coding records outside the region are kept. Results are in stage-1 (file) order whether a transcript came from the pool or was just built, which is what fixes CSQ order.

A region without coordinates queries the whole sequence region, and so assembles every transcript on it.

Return type:

list[Transcript]

Return the records an indexed query over one region reads, assembling nothing.

Unlike the file-backed default this resolves the region into the file’s own spelling, and falls back to chr prefix variants when the name the index declares finds nothing – which happens for an unindexed GXF with no ##sequence-region directive.

iter_features_by_region(region=None, *, seq_region_name=None, start=None, end=None)[source]#

Yield complete transcripts intersecting one query region.

One region is the batch of one: an indexed query cannot serve this, because a transcript’s exons reach outside the queried region, so the answer is the same sequential pass iter_features_by_regions makes. Callers with an index want get_features_by_region, which queries each candidate’s full span instead.

iter_features_by_regions(intervals_by_region)[source]#

Yield only transcripts intersecting reference-space query intervals.

This source’s own method, not part of the FeatureSource contract: a format whose record already carries a whole feature answers each region on its own, and gains nothing from the batch. Here one pass serves every requested interval, so a whole input buffer costs one read of the file rather than one per region.

The record predicate runs before transcript, exon, CDS, and gene models are built, which keeps the unindexed fallback bounded by the current payload rather than the source size.

Parameters:

records_to_features(records)[source]#

Convert a batch of records into transcripts, with a fresh gene and slice context.

The records must be complete and contiguous: every exon, CDS and gene row of each transcript present, in file order. One transcript is many records, so a partial set builds partial models rather than failing – which is why the region and streaming getters are overridden instead of composing this one record at a time.

Fresh dictionaries are passed every time: _build_transcripts defaults to shared mutable dictionaries, which would carry genes and slices over from one call to the next.

Parameters:

records (list[GXFRecord]) – The records to convert, in file order.

Returns:

The transcripts they describe.
