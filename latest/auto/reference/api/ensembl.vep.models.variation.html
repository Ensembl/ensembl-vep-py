Minimises the variation allele by computing the minimal representation of the variant.

Structural variants are not minimised, so this method simply returns the current representation of the structural variant.

shift(force=False)[source]#

Shifts the variation allele to the leftmost position in the sequence.

Currently, this method simply returns the current representation of the structural variant.

Bases: Feature

Represents a variation to genomic sequences in a specific locus.

Variables:

  • stable_id (str | None) – Stable identifier for the variation.

  • allele_string (str | None) – String representation of the alleles.

  • uploaded_locus (Locus | None) – Original region name, position and allele string supplied by the variation source. Its seq_region_name is what output reports and what a run summary counts by; the slice names the same region as the annotation sources spell it.

  • variation_alleles (list[VariationAllele] | None) – List of VariationAllele objects describing the alleles of the variation.

  • is_somatic (bool | None) – Indicates whether the variation is somatic.

  • class_so_term (str | None) – Sequence Ontology term describing the class of the variation.

  • most_severe_consequence (OverlapConsequence | None) – Most severe consequence type for the variation.
