ensembl.vep.cli module#

The vep command line.

The first argument selects the command; when it is not a registered one the default is used, so vep --input_file x.vcf still parses. --config FILE may stand anywhere and is taken off first, so vep --config f.toml corpus describe reaches corpus describe. vep -h lists every command and vep <group> -h the verbs of one group, laid out the way git -h lays out its commands.

ensembl.vep.cli.main(argv=None)[source]#

Run a command and return its exit code.

Parameters:

argv (list[str] | None, default: None) – Arguments without the program name, or None for sys.argv[1:].

Returns:

The runner’s exit code, OK after printing a help page, or USAGE if no

command could be resolved, --config is malformed, or the configuration is invalid or unreadable.

Return type:

ExitCode

ensembl.vep.cli.resolve_command(argv)[source]#

Split arguments into a command name and the arguments that belong to it.

A bare group name resolves to that group’s single runner if it has one, otherwise stays unresolved so the caller can list its verbs.

Only a leading flag, or no arguments at all, means the default command. vep takes no positional arguments, so a leading bare word can only be a command, and one that is not registered is an error rather than something to pass to the default.

Parameters:

argv (list[str]) – Arguments without the program name.

Returns:

The command name and the remaining arguments. The name is empty when

the leading word is not a command, or names a group without one of its verbs.

static record_count(file_path, scan=False)#

Return how many records a VCF file holds, or None when nothing declares it.

The count comes from the file’s index, which answers in one small read. Without an index there is no count unless scan is set, which reads the whole file: an input of a billion lines makes that pass the slowest part of a run, so a caller that only wants it for progress reporting leaves it off and does without the count.

A static method, like parse_file: the count neither depends on the mode a reader was opened in nor disturbs a stream being read.

Parameters:

  • file_path – The VCF file to count.

  • scan (default: False) – Whether to count by reading the file when no index declares it.

ensembl.vep.ensembl_vep_core.batch_overlap_any_interval(variant_mins, variant_maxs, interval_starts, interval_ends, offsets)#

Does each variant span overlap any interval in its own context’s interval list?

The kernel behind overlap_exon/overlap_intron. Interval lists are passed CSR-style – one flat (starts, ends) pair plus an offsets array of length count + 1, where context i owns intervals offsets[i]..offsets[i + 1], so a batch spanning many transcripts is still exactly three arrays and no nesting. Contexts sharing a transcript can point at the same slice, which is the common case for the heavy-locus corpus.
