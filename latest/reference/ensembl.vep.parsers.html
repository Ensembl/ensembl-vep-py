attribute_values(key)#

Return every value for an attribute key, or an empty vector when the key is absent.

Equivalent to attributes.get(key, ()), but a linear scan of the stored pairs instead of building a whole dict per call. A repeated key resolves to its last occurrence, as attributes and first_attribute do.

first_attribute(key)#

Return the first value for an attribute key, or None when the key is absent.

Equivalent to attributes[key][0], but a linear scan of the stored pairs instead of building a whole dict per call.

GFF3 allows for one key with a comma-separated array for multiple values.

For repeated keys, noodles-gff keeps each occurrence as its own pair in self.attributes. The attributes getter above builds a dict via set_item, so a repeated key resolves there to its last occurrence – scanning in reverse here matches that, instead of silently returning a different value for the same key.

static record_count(file_path, scan=False)[source]#

Return the declared VCF record count, if available.

The count comes from the file’s index, which answers in one small read. Without an index there is no count unless scan is set, which reads the whole file; on an input of a billion lines that pass dominates a run, so a caller that only wants the count for progress reporting leaves it off and does without.

Parameters:

  • file_path (str | Path) – The path to the VCF file to count.

  • scan (bool, default: False) – Whether to count by reading the file when no index declares it. Default is False.

Returns:

The record count, or None when no index declares it and scan is False.

int | None
