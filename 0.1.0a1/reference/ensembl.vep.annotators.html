ensembl.vep.annotators.base module#

Annotator protocol shared by all annotation domains.

Annotator is the contract callers depend on. registry.get_annotator returns one without requiring inheritance, allowing Python and native implementations to share the registry. The protocol exposes single-overlap and batch annotation; implementations may derive either operation from the other.

ensembl.vep.annotators.factory module#

Build annotators and run-scoped context from plain values.

Registered strategies accept different keyword arguments, so construction derives supported options from each factory signature instead of maintaining a duplicate table. That is what lets a caller spread a whole configuration section over build_annotator: the options the chosen strategy declares reach it, and the rest are warned about and dropped.

Parameters:

  • batch_size (int, default: 256) – Overlaps per chunk, for the strategies that batch.

  • early_subsumption_skip (bool, default: False) – Skip rules already suppressed by a hit, where supported.

  • zone_map (bool, default: False) – Enable the positional-fact zone map.

  • zone_map_bytes (int, default: 268435456) – Byte budget for the zone map cache.

  • codon_cache (bool, default: False) – Enable the shared-codon edit cache.

  • codon_cache_entries (int, default: 65536) – Maximum codon cache entries.

  • mapper_cache (bool, default: False) – Enable the mapper index cache.

  • mapper_cache_bytes (int, default: 67108864) – Byte budget for the mapper index cache.

  • readthrough (str | Readthrough, default: Readthrough.NONE) – How far translation may run past a destroyed stop codon.

  • fact_cost_override (bool, default: False) – Use the packaged measured fact costs, when building the context.

  • upstream_distance (int, default: 5000) – Bases before a feature’s 5’ end that still count as upstream.

  • downstream_distance (int, default: 5000) – Bases past a feature’s 3’ end that still count as downstream.

  • annotator_context (AnnotatorContext | None, default: None) – A context to share across annotators, or None to build one from the cache arguments.

  • **options (Any) – Further options for the chosen strategy, such as the ones another annotation kind declares. Each is passed on only if that strategy’s factory accepts it; unsupported options are logged as warnings.
