Options for adding a catalogue term.

class ensembl.vep.config.sections.catalogue.add.CatalogueAddConfig(*, term=None, accession=None, rank=None, tier=3, impact=None, so_parent=(), subsumes=(), no_derive_subsumes=False, when=None, allow_missing_when=False, notes=None)[source]#

Bases: ConfigSection

The term being added.

Variables:

  • term (str | None) – The SO term to add.

  • accession (str | None) – Its SO accession.

  • rank (int | None) – 1-based rank to insert at, or None to append after the highest.

  • tier (int) – Tier grouping.

  • impact (str | None) – Impact bucket.

  • so_parent (tuple[str, ...]) – SO parent accessions, used to derive subsumes.

  • subsumes (tuple[str, ...]) – Extra terms to subsume, on top of the derived ones.

  • no_derive_subsumes (bool) – Skip deriving from so_parent.

  • when (str | None) – The when payload as JSON. Never inferred: a wrong formula is the one error conformance cannot catch, since every annotator would agree on it.

  • allow_missing_when (bool) – Write the entry as a placeholder rather than refusing.

  • notes (str | None) – Free-text notes.

ensembl.vep.config.sections.catalogue.show module#

Options for listing what the catalogue and fact registry contain.

class ensembl.vep.config.sections.catalogue.show.CatalogueShowConfig(*, subject='terms', select=None, graph=False, output_format=None, sort=None, output_file=None)[source]#

Bases: ConfigSection

What to list, and how to render it.

Variables:

  • subject (str) – Whether to list the catalogue’s terms or the registered facts.

  • select (str | None) – Show only the term or fact with this name, or None for all of them. In graph mode it keeps that node and whatever it connects to directly.

  • graph (bool) – Draw the subject as a graph. Use --output_format to set the file format, which defaults to svg when --graph is given. Unselected SVG terms are embedded in a linked HTML catalogue.

  • output_format (str | None) – Output format. If --graph is given, must be a valid graph format.

  • sort (str | None) – Row order, or None for the subject’s natural order – catalogue rank for terms, cost tier for facts.

  • output_file (Path | None) – Where to write, or None for stdout.

ensembl.vep.config.sections.catalogue.write module#

Permission to change the catalogue on disk.

class ensembl.vep.config.sections.catalogue.write.CatalogueWriteConfig(*, catalogue_overwrite=False, dry_run=False)[source]#

Bases: ConfigSection

Read only by the verbs that change the catalogue, so the listing verbs never offer it.

Variables:

  • catalogue_overwrite (bool) – Permit writing the packaged catalogue in place. Without this, or an explicit path, a write is refused: an installed vep must not silently rewrite its own wheel.

  • dry_run (bool) – Report the change and its validation without writing.
