# Homo sapiens GRCh38 example data

The files are derived from:

- the [Ensembl VEP (Perl) release 116 example VCF](https://github.com/Ensembl/ensembl-vep/blob/release/116/examples/homo_sapiens_GRCh38.vcf);
- the Ensembl 2026_04 [GRCh38.p14 unmasked reference FASTA](https://ftp.ebi.ac.uk/pub/ensemblorganisms/GCA/000/001/405/29/ensembl/2026_04/genome/unmasked.fa.bgz);
- the Ensembl 2026_04 [GRCh38.p14 gene set](https://ftp.ebi.ac.uk/pub/ensemblorganisms/GCA/000/001/405/29/ensembl/2026_04/geneset/genes.gtf.bgz).

Only chromosome 22 is included. `unmasked.fa.bgz` and `genes.gtf.bgz` are bgzip-compressed and their random-access indexes are stored beside them.
